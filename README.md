# AutoRent — көлік жалға беру платформасы

PHP және MySQL қолданып жасалған веб-қосымша. Пайдаланушылар көліктер каталогын көріп, қажетті күндерге көлікті брондай алады. Әкімші (admin) көліктер мен брондауларды басқарады.

> Жеке жобалық тапсырма, PHP курсы. Жоба 8 аптаға созылады (8–15 апта).

## Жобаның мақсаты

Көлік жалға беру процесін автоматтандыру: көліктер каталогын жүргізу, күндер бойынша брондау, күндердің қиылысуын тексеру және жалдау бағасын автоматты есептеу.

## Технологиялар

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP 8 (PDO)
- **Дерекқор:** MySQL
- **Орта:** XAMPP (локальды), InfinityFree (хостинг)

## Негізгі мүмкіндіктер

- Тіркелу, кіру және шығу (парольдер `password_hash()` арқылы сақталады)
- Көліктерді қосу, көрсету, өңдеу және жою (CRUD, тек admin)
- Көлікті күндер аралығына брондау
- Бір көлікті қиылысатын күндерге екі рет брондауға жол бермеу
- Жалдау бағасын күн санына қарай автоматты есептеу
- Іздеу (марка/модель), сүзу (санат, баға, бос күндер) және сұрыптау, пагинация
- Рөлдер: `user` (клиент) және `admin` (әкімші)
- Валидация және қауіпсіздік (prepared statements, `htmlspecialchars()`)
- Қосымша функция: 14-аптада нақтыланады (мысалы, көлік суретін жүктеу)

## Апталық есептер

### 8-апта: Жоспарлау және репозиторий

**Орындалған жұмыс**
- Жоба тақырыбы таңдалды: AutoRent, көлік жалға беру платформасы. Мақсаты мен негізгі мүмкіндіктері сипатталды.
- Беттер тізімі жасалды (9 бет).
- Дерекқор құрылымы (ER-диаграмма) сызылды: `users`, `categories`, `cars`, `bookings` кестелері және олардың арасындағы байланыстар.
- GitHub-та репозиторий ашылды, README жазылды.

**Жобаның күйі:** ~10%

**Мәселелер және шешімдері:** елеулі мәселе болған жоқ.

**Келесі аптаға жоспар:** Figma-да макет жасау, HTML/CSS/JavaScript интерфейсін іске асыру.

**GitHub:** [коммиттер тарихы](https://github.com/Aselya23/AutoRent/commits/main)

### 9-апта: Пайдаланушы интерфейсі (frontend)

**Орындалған жұмыс**
- Figma-да негізгі экрандардың макеті жасалды: басты бет (каталог), кіру, тіркелу, көлік беті.
- HTML, CSS және JavaScript көмегімен адаптивті интерфейс іске асырылды: басты бет, кіру және тіркелу формалары.
- JavaScript арқылы көліктерді іздеу, санат және баға бойынша сүзу, сұрыптау, көлік санын көрсету жасалды.
- Телефон, планшет және компьютер экрандарына арналған адаптивті стильдер қосылды.

**Жобаның күйі:** ~25%

**Мәселелер және шешімдері:** Figma-да бет (Frame) мөлдірлігі кездейсоқ 10%-ға түсіп кетті, Opacity мәнін 100% қылып түзеттім.

**Келесі аптаға жоспар:** беттерді PHP файлдарына көшіру, `include` арқылы header/footer бөлу, формаларды өңдеу.

**GitHub:** [коммиттер тарихы](https://github.com/Aselya23/AutoRent/commits/main)

### 10-апта: PHP негіздері және серверлік құрылым

**Орындалған жұмыс**
- Статикалық беттер PHP-ге көшірілді: `index.php`, `car.php`, `login.php`, `register.php`.
- Қайталанатын бөліктер `include` арқылы бөлінді: `includes/header.php`, `includes/footer.php`. Уақытша деректер мен көмекші функциялар `includes/data.php` ішінде.
- Іздеу, санат бойынша сүзу және сұрыптау `$_GET` арқылы жұмыс істейді, көлік беті `car.php?id=` арқылы ашылады.
- Тіркелу, кіру және брондау формалары `$_POST` арқылы өңделеді, деректер сервер жағында тексеріледі (email, телефон, құпиясөз, брондау күндері).
- Экранға шығатын мәтін `htmlspecialchars()` арқылы қорғалды (XSS).
- Жоба XAMPP (Apache) арқылы `localhost`-та тексерілді.

**Жобаның күйі:** ~40%

**Мәселелер және шешімдері**
- XAMPP қалтасы стандартты емес жолда тұрды, жобаны дұрыс `htdocs` қалтасына көшірдім.
- PHP файлы `file:///` арқылы жұмыс істемейді, оны `http://localhost/...` арқылы ашу керек екенін түсіндім.
- XAMPP-та MySQL порты (3306) бос емес, оны 11-аптада дерекқорға көшкенде шешемін.

**Келесі аптаға жоспар:** MySQL дерекқорын құру, PDO арқылы қосылу, тіркеуде `password_hash()`, кіру жүйесі және сессиялар, шығу (logout).

**GitHub:** [коммиттер тарихы](https://github.com/Aselya23/AutoRent/commits/main)
